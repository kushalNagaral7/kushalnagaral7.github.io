## 📌 About the Project

This repository contains my personal portfolio website, built to introduce me, highlight my interests and provide links to my online profiles.

The website is published using **GitHub Pages**.

## ✨ Features

- 🌙 Dark, modern visual design
- 📱 Responsive layout for mobile and desktop
- 👤 Personal introduction and portrait
- 🚀 Project showcase section
- 🧰 Technology and learning interests
- 🔗 Contact links to GitHub, Instagram, LinkedIn and email
- ✨ Subtle animations and visual effects
- ♿ Reduced-motion support


The portrait filename above assumes the image in the repository is `profile.jpg`.

## 🚀 Run It Yourself

1. Open or download this repository.
2. Keep `index.html` and your portrait image in the same folder.
3. Open `index.html` in a browser to preview the website.
4. To publish your own version, create a GitHub repository and enable GitHub Pages in its settings.

## 🔧 Customization

- Edit `index.html` to change the content, colors and layout.
- Replace `profile.jpg` with your own portrait, keeping the filename consistent.
- Update the social links with your own profiles.
- Commit your changes to publish updates through GitHub Pages.
